# Discord Krisp not working?

<DisclosureNotice />

**When Krisp stops working in Discord, it is almost always one of three things: Krisp is not selected in Voice and Video settings, Discord does not have microphone permission, or your CPU is overloaded so Discord disabled it. Here is the fix, in order.**

## 1. Turn Krisp on in Discord

1. Open Discord **User Settings > Voice and Video**.
2. Scroll to **Noise Suppression** and select **Krisp** (not Standard or None).
3. Set your **Input Device** to your real microphone.
4. Test with the **"Let's Check"** mic test.

## 2. Fix microphone permissions

If Discord picks up nothing at all:

- On **Windows**, go to **Settings > Privacy and security > Microphone**, turn on microphone access, and make sure Discord is allowed.
- On **Mac**, go to **System Settings > Privacy and Security > Microphone** and enable Discord.
- In Discord, confirm the input volume bar moves when you speak.

## 3. High CPU (Discord turns Krisp off)

Discord will automatically disable Krisp when your CPU is too busy, to keep the call stable. If Krisp keeps switching itself off:

- Close CPU-heavy apps and games, then re-enable Krisp.
- Lower Discord's other processing, and avoid running a second noise-suppression tool at the same time.

## 4. When to use the standalone Krisp app instead

Discord's built-in Krisp only cleans **your outgoing mic**, inside Discord. If it keeps failing, or you also want the noise gone from what **you hear** and clean audio in other apps, the standalone Krisp app is more capable and more reliable. Set your Discord input to **Krisp Microphone** after installing it. See [Discord: Krisp vs Standard](/docs/compare/krisp-app-vs-discord/).
