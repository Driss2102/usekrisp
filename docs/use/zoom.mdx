# Krisp on Zoom

<DisclosureNotice />

Zoom has its own noise suppression, but it is limited and only cleans your outgoing audio. Krisp cleans both directions and works far more aggressively on background noise. Here is how to set it up.

## Step by step

1. Download and install Krisp, then open it.
2. In Krisp, set your real microphone and speaker as the input and output devices, and toggle noise cancellation on.
3. Open Zoom, go to **Settings > Audio**.
4. Under **Microphone**, choose **Krisp Microphone**. Under **Speaker**, choose **Krisp Speaker**.
5. Set Zoom's own **Background noise suppression** to **Low**. This stops Zoom from fighting Krisp, so Krisp does the heavy lifting.

That is it. Krisp now removes keyboard noise, fans, traffic, and background chatter from your calls.
